# Day 5 — User Stories

The following stories translate the documented needs into user-focused goals using the required format.

### US-01 — Guest / New Customer

As a guest customer, I want to browse and compare available flower arrangements, so that I can find an arrangement that suits my occasion and preferences.

### US-02 — Guest / New Customer

As a guest customer, I want to customize an arrangement by choosing available size, colors, message, and extras, so that I can create an arrangement that fits my needs.

### US-03 — Guest / New Customer

As a guest customer, I want to see product availability and available delivery or pickup options before checkout, so that I can choose an option that can actually be fulfilled.

### US-04 — Guest / New Customer

As a guest customer, I want to complete an order without creating an account, so that I can purchase flowers conveniently.

### US-05 — Customer

As a customer, I want to review and change my order before paying, so that I can correct any details before placing the order.

### US-06 — Customer

As a customer, I want to pay securely using supported cards or digital wallets, so that I can complete my purchase safely.

### US-07 — Customer

As a customer, I want to receive confirmation and status updates for my order, so that I know whether my order has been confirmed, prepared, and delivered or collected.

### US-08 — Returning Customer

As a returning customer, I want to save recipient details, addresses, and favorite arrangements, so that I can place future orders more easily.

### US-09 — Returning Customer

As a returning customer, I want to view my previous orders and reorder an arrangement, so that I can quickly repeat a successful purchase.

### US-10 — Returning Customer

As a returning customer, I want to earn and redeem loyalty rewards, so that I can receive benefits from continued purchases and referrals.

### US-11 — Customer — AI Support

As a customer, I want the AI assistant to answer questions about flowers, arrangements, prices, care, occasions, availability, delivery, and promotions, so that I can get help without waiting for staff.

### US-12 — Customer — AI Support

As a customer, I want the AI assistant to recommend arrangements and complementary products based on my occasion, budget, colors, and preferences, so that I can make a more informed choice.

### US-13 — Customer — AI Support

As a customer, I want the AI assistant to add recommended products to my cart while allowing me to review everything myself, so that I can use AI assistance without giving it control of checkout or payment.

### US-14 — Customer — AI Support

As a customer, I want to communicate with the AI assistant in English or Irish, so that I can use the service in my preferred language.

### US-15 — Customer — AI Support

As a customer, I want unusual, uncertain, custom, or complaint-related requests to be handed to staff, so that I receive accurate help instead of an AI-generated guess.

### US-16 — Staff

As a staff member, I want to view and update order statuses, delivery or pickup information, and relevant customer details, so that I can manage orders accurately.

### US-17 — Staff

As a staff member, I want to view inventory quantities and low-stock or unavailable items clearly, so that I can identify stock issues before accepting orders.

### US-18 — Staff

As a staff member, I want to record inventory received, used, damaged, or unavailable quantities, so that stock information remains accurate.

### US-19 — Manager

As a manager, I want to create and manage arrangements and prices without technical assistance, so that the website reflects the florist’s current products and pricing.

### US-20 — Manager

As a manager, I want to create, schedule, edit, and end promotions without technical assistance, so that seasonal offers remain current.

### US-21 — Manager

As a manager, I want to manage seasonal content and holiday order limits without technical assistance, so that the website reflects current business conditions.

### US-22 — Customer

As a customer, I want to see whether same-day delivery is available before ordering, so that I know whether my order can be delivered on the day I need it.

### US-23 — Customer

As a customer, I want to subscribe to recurring flower deliveries with my preferred schedule, duration, size, and style, so that I can receive flowers regularly without placing each order manually.

### US-24 — Customer

As a customer, I want to purchase and redeem digital gift cards, so that I can give or use a flexible gift option through the website.

### US-25 — Customer

As a wedding or event customer, I want to submit my event date, venue, guest count, floral needs, budget, style, and inspiration photos, so that Lily can review my request and prepare a personalized quote.

### US-26 — Customer

As a customer, I want to contact the florist through available human support channels and have my inquiry recorded, so that I can receive help for questions or issues that require staff.

### US-27 — Staff

As a staff member, I want to manage delivery capacity and record failed-delivery outcomes, so that delivery schedules remain accurate and customers can be contacted for redelivery or pickup when needed.

### US-28 — Manager

As a manager, I want to view reports on sales, order volume, busy periods, popular arrangements, inventory, deliveries, and loyalty activity, so that I can monitor business operations and make informed decisions.

### US-29 — Owner / Admin

As the owner or administrator, I want to control staff permissions and access to sensitive information and settings, so that each user can access only what their role requires.

### US-30 — Customer

As a customer, I want to request access to or deletion of my personal information where appropriate, so that I can exercise my privacy rights.

# Step 5 Check — Persona Coverage

Represented: Guest / New Customer, Returning Customer, Customer, Customer using AI Support, Staff, Manager, and Owner / Admin.

All six core personas/actors from the Requirements Inventory are represented. The expanded set contains 30 stories because additional Lily-supported functional findings were separated into independently actionable stories; the 15–20 figure is the initial target, not a hard maximum.

Coverage note: The story set was expanded beyond the initial 15–20 target to preserve traceability for documented functional findings from Lily’s interview. Technical, reliability, accessibility, responsive, and future-integration findings remain candidates for formal non-functional or system requirements rather than separate user stories.
